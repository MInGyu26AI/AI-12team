# 외부 서비스 연결과 문자 인식

노션, 구글 문서, 올린 파일(PDF·이미지)의 글을 읽어 오는 방법과 그 글이 어디로 가는지 적었습니다. 코드는 `collector/connectors/`에 있고, 시험은 `checks/check_connectors.py`입니다. 개인정보 전체 규칙은 [privacy.md](privacy.md)입니다.

## 무엇을 읽나

- **노션·구글 문서.** 사용자가 고른 범위(페이지·문서)만 읽습니다. 수집 중일 때 5분마다 읽고, 로컬 페이지 `http://127.0.0.1:<포트>/connectors`의 '지금 가져오기'로도 읽습니다. 일시중지·종료 중에는 읽지 않습니다.
- **내 글만.** 문서 절마다 작성자를 판단해서 남이 쓴 절은 PC에도 저장하지 않습니다. 작성자를 알 수 없는 본문(구글 문서 본문 등)은 사용자가 그 문서의 담당자라고 확인했을 때만 내 글로 넣습니다.
- **올린 파일.** 웹 화면이 PDF를 쪽 이미지로 바꾸고, 이 PC에서 문자를 인식해(`files.ocr`) 글로 받습니다. 글자가 이미 들어 있는 파일은 브라우저에서 바로 읽습니다.
- **형식.** 글은 절 하나가 한 턴이고, 2000자를 넘으면 문단 경계에서 쪼갭니다. 같은 내용은 한 번만 들어갑니다(공백만 바뀐 것은 같은 내용). 고친 절은 새 글로 들어갑니다. `docs/sync-contract.md` 2장에 필드가 있습니다.

## 연결 정보(토큰)는 어디에 있나

- 이 PC의 `<상태 폴더>/connectors/<서비스>.json` 한 곳입니다. 폴더는 본인만, 파일은 본인만 읽고 쓰는 권한(0600)으로 만듭니다. 다른 계정이 읽을 수 있는 파일은 쓰지 않습니다.
- 토큰은 로컬 페이지에서만 입력합니다. 배포 웹, 팀 서버, 개인 DB, 로그, RPC 응답에는 없습니다. 상태에는 `tokenSet: true/false`만 나옵니다. 오류는 종류와 HTTP 상태(예: `rate_limit 429`)만 남기고 서비스가 보낸 내용은 남기지 않습니다.
- '연결 끊기'는 이 PC의 파일을 지웁니다. 서비스 쪽 권한(노션 통합, 구글 앱 접근)은 그 서비스 설정에서도 지우세요.

## PC 밖으로 나가는 것

- **검사 전에는 아무것도 나가지 않습니다.** 읽어 온 글은 대화와 같은 입구(`turns.append`)로 들어가 저장 전 가림, 이 기기의 개인정보 검사, 개인 검토함 승인을 거칩니다. 허용된 정리본만 외부 AI 분류로 가고, 승인한 카드만 팀 서버로 갑니다.
- 읽는 일 자체는 이 PC가 노션·구글 서버에 직접 요청하는 것입니다(토큰을 붙여서). 팀 서버는 거치지 않습니다.
- **문자 인식은 이 PC 안에서만 합니다.** 이 PC의 Ollama(`OLLAMA_HOST`, 기본 `http://127.0.0.1:11434`)만 부릅니다. 루프백이 아닌 주소와 원격(cloud) 모델은 거절합니다. 쓰는 모델은 `SYNCUP_VISION_MODEL`, 없으면 설치된 것 중 `gemma4:e4b`, `gemma4:12b`, `gemma4:e4b-it-qat` 순서의 첫째입니다. 모델이 없으면 쪽마다 `model_unavailable`로 답하고 이미지는 어디로도 가지 않습니다.
- 인식한 글도 다른 입력과 같이 `turns.append`를 거칩니다(`site: file-upload`).

## 한계

- 쪽 이미지는 디코드 후 8 MB까지(`too_large`), 쪽마다 120초까지 기다립니다. 웹·확장·수집기가 한 요청을 4 MB로 제한하므로(`RPC_LIMIT`), 실제로는 요청당 쪽 하나를 줄여서(긴 변 약 1600px) 보내세요.
- 인식 품질은 모델에 따릅니다. 한국어·영어 표 하나짜리 쪽으로 `gemma4:e4b`를 한 번 시험했을 때 글자를 정확히 읽었지만, 손글씨·흐린 사진·여러 단 문서는 시험하지 않았습니다.

## 서비스 추가하기 (개발자)

`collector/connectors/<서비스>.py`에서 `base.Provider`를 이어받고 맨 아래에서 `register()`합니다(`notion.py`, `google_docs.py`는 `load_providers()`가 찾아 불러옵니다).

| 메서드 | 하는 일 |
|---|---|
| `status(pipeline)` | `{'connected', 'tokenSet', 'needs'}` |
| `setup_html(pipeline)` | 로컬 페이지에 넣을 입력칸(`<form>`·csrf·저장 단추는 페이지가 붙임) |
| `handle_setup(pipeline, form)` | 토큰·설정 저장(`base.save_token`), 한국어 안내문 반환 |
| `fetch(pipeline, scope)` | `(문서 목록, 새 커서)`. 문서는 `{source_id, title, url?, modified, sections: [{heading, text, author_is_me}]}` |
| `disconnect(pipeline)` | 서비스 쪽 취소가 있으면 부르고 토큰 파일 삭제(기본은 파일 삭제) |

`author_is_me`가 `False`인 절은 틀이 버리고, `None`(작성자 모름)은 담당자 확인을 거친 뒤 내 글로 넣을 때만 씁니다. 토큰 파일 값은 `status`·화면·오류 문구에 쓰지 마세요(쓰면 틀이 `…`로 가립니다).
