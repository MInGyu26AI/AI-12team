# 싱크업 분류 기준 (요약)
팀원 한 명이 AI와 나눈 대화에서 뽑은 문장(u1, u2, ...)을 판정한다. 화자가 "AI"인 발화는 ChatGPT 등의 답변이다.

관련성: 팀 이름 + 프로젝트 주제와 관련 있으면 related. 점심·약속·다른 수업·건강·컨디션·개인 사정·개인 취향은 personal.
개인 질문에 대한 AI 답변도 personal. 팀 일정에 영향을 줘도 개인 사정("치과 때문에 회의 늦어", "과외 끝나고 6시부터 돼")은 personal.

표시:
- decision: 팀이 정한 것. "~하자", "~로 간다", "~하기로 했어", "~하려고", "~할 거야", "~로 할게", "~로 바꿨어".
  요청·질문 안에 전제로 들어 있는 결정도 결정이다 ("MySQL 기준으로 테이블 짜 줘" → DB = MySQL, "모바일은 빼니까 ~" → 지원 범위 = 웹만).
- todo: 누군가 해야 할 팀 작업과 담당 ("내가 내일까지 만들게", "도윤이가 맡아 줘", "소희가 정리해 주기로 했어").
  발표자·사회자·팀장처럼 자리를 정하는 말("발표자는 소희로 하자")은 decision.
- research: 알게 된 사실·자료·외부 조건·팀 상황 정보 ("~래", "교수님이 ~랬어", "다들 자바는 처음이래", AI 답변 속 기술 사실).
- none: 제안·질문("~하면 어때?"), AI에게 하는 요청("~해 줘"), AI의 추천·조언·예시·코드·작성 문구, 이미 나온 결정을 AI가 반복·요약한 것.
  AI가 말한 것은 decision·todo가 될 수 없다.

소주제: 주제·목표(주제·타깃·서비스명·범위) / 자료 조사(조사 활동·비교 결과) / 작업·결과물(만드는 것: 코드·기능·디자인·기술 선택) /
역할·일정(역할 분담 방식·팀 내부 마감·회의 시간·정산) / 과제 조건·피드백(교수님·주최 측 조건·평가 기준) / 발표·제출(발표자·발표 자료·제출) / 기타.
할 일의 소주제는 맡은 일의 내용으로 정한다 (보고서 쓰기 → 작업·결과물).

변경: 결정이 기존 팀 결정과 같은 대상에 다른 값을 정하거나, "바꾸자·옮겼어·대신·빼기로·도 넣자"처럼 바꾸는 표현이면 변경이다.
